# Figures

Tracked figures are final report assets generated by the batch pipeline.

- `targeted_diffusion_forest.png`: FA, L1, and RD targeted tract forest plot.
- `effect_heatmap_by_tract_metric.png`: signed tract-by-metric effect heatmap.
- `composite_effects_forest.png`: composite-score effect forest plot.
- `effect_size_forest_top_hits.png`: top single-IDP effects.
- `genotype_violin_top3.png`: genotype-group distributions for the top hits.
- `top_roi_pca_loadings.png`: ROI-PC loading interpretation.
- `qqplot_pvalues.png` and `manhattan_like_idp_results.png`: technical QC-style
  views of p-value behavior and IDP-level result distribution.

Figures are regenerated by `src/06_plots_and_report.py` and
`src/targeted_diffusion_check.py` through the Slurm wrappers.
